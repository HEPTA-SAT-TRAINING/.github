# HEPTA-SAT

Welcome to the **HEPTA-SAT TRAINING**.
Before starting the HEPTA-SAT TRAINING, please complete the following setup.

# 1. Arduino IDE Setup

Download and install Arduino IDE.

**[Download Arduino IDE](https://www.arduino.cc/en/software)**

Open:

`File → Preferences → Additional Boards Manager URLs`

and add:

```text
https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json
```

Open **Boards Manager**, search for `pico`, and install:

`Raspberry Pi Pico/RP2040/RP2350`

Then select:

`Tools → Board → Generic Raspberry Pi Pico 2`

---

# 2. GitHub Desktop Setup

Download and install GitHub Desktop.

**[Download GitHub Desktop](https://desktop.github.com/download/)**

To download a HEPTA-SAT Lab repository:

`Code → Open with GitHub Desktop → Clone`

> [!IMPORTANT]
> Please complete **Sections 1 and 2 before starting the training**.
